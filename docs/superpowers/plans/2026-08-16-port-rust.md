# Port do hog-audio para Rust — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reimplementar em Rust tudo que o `hog-audio` faz em C++ e provar, com oráculo externo, que a versão Rust preserva bit-perfect.

**Architecture:** Os dois binários coexistem em `cpp/` e `rust/`. Ambos ganham um modo `--dump` que percorre o pipeline completo (decodificador → ring buffer → consumidor) gravando em arquivo o que iria ao IOProc. O ffmpeg extrai o PCM de referência do FLAC e um script compara byte a byte.

**Tech Stack:** Rust 1.93 + `coreaudio-sys` 0.2.18 (dependência única). C++20 + CMake. Python 3 para o verificador.

**Spec:** `docs/superpowers/specs/2026-08-16-port-rust-design.md`

## Global Constraints

- **Dependência Rust única: `coreaudio-sys`.** Proibido `clap`, `rtrb`, `anyhow`, qualquer outra crate. O C++ não tem dependência externa; a comparação exige simetria.
- **O ring buffer é portado, não substituído** por crate pronta.
- **Parsing de CLI manual**, sem biblioteca de argumentos.
- **O IOProc e o consumidor do dump não podem alocar, travar, imprimir ou entrar em syscall.** Só `copy_from_slice`, `write_bytes` e atômicos.
- **Nomes de código em inglês**; mensagens ao usuário em pt-BR, idênticas às do C++.
- **Commits em pt-BR no infinitivo**, formato Conventional Commits (`tipo(escopo): descrição`, ≤72 chars, sem acento no subject).
- Toda leitura do ring buffer passa por `aligned_read_size` — nunca consumir bytes soltos.

```rust
//! Helpers sobre a API de propriedades do Core Audio. Toda a travessia de FFI passa por aqui,
//! para que o resto do código não repita o padrão de ponteiro e tamanho.

use coreaudio_sys::*;
use std::mem::{size_of, MaybeUninit};

pub fn property_address(
    selector: u32,
    scope: u32,
) -> AudioObjectPropertyAddress {
    AudioObjectPropertyAddress {
        mSelector: selector,
        mScope: scope,
        mElement: kAudioObjectPropertyElementMain,
    }
}

pub fn get_property<T>(
    object: AudioObjectID,
    address: &AudioObjectPropertyAddress,
) -> Result<T, OSStatus> {
    let mut value = MaybeUninit::<T>::uninit();
    let mut size = size_of::<T>() as u32;
    let status = unsafe {
        AudioObjectGetPropertyData(
            object,
            address,
            0,
            std::ptr::null(),
            &mut size,
            value.as_mut_ptr() as *mut _,
        )
    };
    if status == 0 {
        Ok(unsafe { value.assume_init() })
    } else {
        Err(status)
    }
}

pub fn set_property<T>(
    object: AudioObjectID,
    address: &AudioObjectPropertyAddress,
    value: &T,
) -> OSStatus {
    unsafe {
        AudioObjectSetPropertyData(
            object,
            address,
            0,
            std::ptr::null(),
            size_of::<T>() as u32,
            value as *const T as *const _,
        )
    }
}

pub fn get_property_array<T: Clone + Default>(
    object: AudioObjectID,
    address: &AudioObjectPropertyAddress,
) -> Result<Vec<T>, OSStatus> {
    let mut size: u32 = 0;
    let status = unsafe {
        AudioObjectGetPropertyDataSize(object, address, 0, std::ptr::null(), &mut size)
    };
    if status != 0 {
        return Err(status);
    }
    let count = size as usize / size_of::<T>();
    let mut out = vec![T::default(); count];
    if count == 0 {
        return Ok(out);
    }
    let status = unsafe {
        AudioObjectGetPropertyData(
            object,
            address,
            0,
            std::ptr::null(),
            &mut size,
            out.as_mut_ptr() as *mut _,
        )
    };
    if status == 0 {
        Ok(out)
    } else {
        Err(status)
    }
}

/// Formata um OSStatus como fourcc legível quando possível, senão como número.
pub fn os_status_text(status: OSStatus) -> String {
    let value = status as u32;
    let chars = [
        ((value >> 24) & 0xFF) as u8,
        ((value >> 16) & 0xFF) as u8,
        ((value >> 8) & 0xFF) as u8,
        (value & 0xFF) as u8,
    ];
    if chars.iter().all(|c| c.is_ascii_graphic()) {
        format!("{} ({})", String::from_utf8_lossy(&chars), status)
    } else {
        format!("{status}")
    }
}
```

- [ ] **Step 1: Implementar `query_default_output_device`**

Ordem: device padrão → nome (`CFStringRef` → `String`, liberar) → streams de saída (pegar o primeiro) → rates disponíveis → formatos físicos disponíveis. Ao converter formatos, ignorar os que não são `kAudioFormatLinearPCM`, e preencher `sample_rate_minimum`/`maximum` a partir de `mSampleRateRange` (formatos de faixa contínua trazem `mSampleRate` zerado). Ler canais do virtual format atual, nominal rate e volume (volume negativo se ausente).

- [ ] **Step 2: Implementar `acquire` respeitando a ordem que o C++ estabeleceu**

Ordem obrigatória, cada passo com o motivo:
1. Guarda contra reaquisição (`if saved_formats || hogged` → erro), senão o estado original salvo seria sobrescrito pelo já modificado.
2. Salvar `original_rate`, `original_physical`, `original_virtual`.
3. **Hog primeiro** — só o dono exclusivo troca o formato físico de forma confiável. Marcar `hogged = true` assim que o set retornar `noErr`, antes de conferir o dono.
4. Se o rate difere, setar e **esperar confirmar** (`wait_for_rate`, poll de 10 ms até 2 s). O HAL muda o rate de forma assíncrona: sem a espera, o formato seria escrito sobre um estado prestes a mudar.
5. Setar o formato físico, com `mSampleRate` preenchido com o rate negociado (formatos de faixa contínua chegam com a taxa zerada).
6. Tentar travar o virtual format igual ao físico; guardar se conseguiu.
7. Reler o virtual format efetivo — é o que o IOProc vai ver.

- [ ] **Step 3: Implementar `restore` e `Drop`**

Ordem inversa: stop → destruir IOProc → rate (com `wait_for_rate`) → formato físico → formato virtual → volume (Task 8) → soltar hog. Acumular falhas em `restore_error` e devolvê-las por `finish()`.

- [ ] **Step 1: Implementar `write_volume_confirmed` (privado) e `set_volume`**

Armadilha do Core Audio que o C++ descobriu e que **precisa ser reproduzida**: a primeira escrita de volume após uma reconfiguração de formato é descartada em silêncio — devolve `noErr` e a leitura imediata retorna o valor pedido, vindo de cache. A confirmação só é válida após uma pausa:

```rust
fn write_volume_confirmed(&self, target: f32) -> bool {
    let address = ffi::property_address(
        kAudioDevicePropertyVolumeScalar, kAudioObjectPropertyScopeOutput);
    for _ in 0..20 {
        ffi::set_property(self.device_id, &address, &target);
        std::thread::sleep(std::time::Duration::from_millis(30));
        if let Ok(current) = ffi::get_property::<f32>(self.device_id, &address) {
            if (current - target).abs() < 0.005 { return true; }
        }
    }
    false
}
```

`set_volume` faz clamp em [0,1], verifica `AudioObjectHasProperty` e `AudioObjectIsPropertySettable`, guarda `original_volume` na primeira chamada, e falha se `write_volume_confirmed` não confirmar — porque um pedido de volume não cumprido significa som mais alto do que o pedido.

- [ ] **Step 2: Implementar `read_volume` e `decibels_to_scalar`**

`read_volume` lê `kAudioDevicePropertyVolumeScalar` e `kAudioDevicePropertyVolumeDecibels` — os valores **reais**. Não existe conversão inversa: `kAudioDevicePropertyVolumeScalarToDecibels` do HAL usa curva linear que **não corresponde** à aplicada (informa −50,8 dB onde o device está a −35,1 dB), então o valor exibido sempre vem do hardware. `decibels_to_scalar` usa `kAudioDevicePropertyVolumeDecibelsToScalar`, que é exato (verificado em 5 pontos).

- [ ] **Step 3: Incluir a restauração de volume no `restore`**

Depois dos formatos (a reconfiguração descarta escritas) e **antes** de soltar o hog (para não disputar o device), usando `write_volume_confirmed`.

- [ ] **Step 4: Implementar `start`/`stop`**

`AudioDeviceCreateIOProcID` + `AudioDeviceStart`; `stop` chama `AudioDeviceStop` se estiver rodando.

- [ ] **Step 1: Estrutura `Playback` e o IOProc**

```rust
struct Playback {
    ring: ring::RingBuffer,
    producer_done: AtomicBool,
    finished: AtomicBool,
    underruns: AtomicU64,
    bytes_per_frame: u32,
    bytes_per_sample: u32,
    channels: u32,
    non_interleaved: bool,
    scratch: UnsafeCell<Vec<u8>>,
}
```

O IOProc é `extern "C"` e roda em thread de tempo real. **Nada de alocar, travar, imprimir ou entrar em syscall** — só `copy_from_slice`, `write_bytes` e atômicos. Preencher com zero é o único preenchimento seguro: memória não inicializada enviada ao DAC vira ruído branco em volume total. Toda leitura passa por `aligned_read_size`; buffer curto, canal excedente ou pedido maior que o `scratch` resultam em silêncio.

- [ ] **Step 3: Orquestração**

Ordem: instalar handlers de sinal **no topo**, antes de qualquer coisa tocar no device (senão há janela em que um Ctrl+C mata o processo sem restaurar) → abrir arquivo → consultar device → imprimir relatório → negociar → se `--info`, sair → `acquire` → aplicar volume → montar client format → validar → conferir formato efetivo → `--dump` (Task 10) ou reprodução normal.

- [ ] **Step 4: Client format e validação**

`bytes_per_frame` vem do device, **nunca** de `bits_per_channel / 8`: um formato pode carregar 24 bits em container de 32, e presumir empacotamento faria o decodificador escrever com um passo e o callback ler com outro — ruído branco. Se não intercalado, multiplicar por canais. Validar com `format::validate_interleaved_format` e comparar com o formato efetivo do decodificador; divergindo, parar antes de tocar.

- [ ] **Step 5: Thread produtora, pré-enchimento e laço principal**

Produtora lê blocos de 64 KB e escreve no ring. Pré-encher metade do ring antes de `start`. Laço principal dorme 50 ms até terminar ou ser interrompido. Guard de thread que garante o join mesmo em erro — uma `JoinHandle` não unida não é problema em Rust como em C++, mas a thread precisa ser sinalizada e aguardada para o `Drop` do device rodar na ordem certa.

- [ ] **Step 1: Implementar no C++**

```cpp
// Simula o IOProc: mesmos blocos, mesma regra de alinhamento, consumidor em disco.
// Um atalho que apenas decodificasse e gravasse pularia ring buffer, alinhamento e
// desintercalação — exatamente onde estiveram os bugs mais caros deste projeto.
constexpr std::uint32_t kBlockFrames = 512;
std::vector<std::uint8_t> block(kBlockFrames * client.mBytesPerFrame);
std::FILE* out = std::fopen(dumpPath.c_str(), "wb");
if (out == nullptr) { std::fprintf(stderr, "erro: não consegui criar %s\n", dumpPath.c_str()); return 1; }

std::uint64_t framesWritten = 0;
while (true) {
    const std::size_t need = block.size();
    const std::size_t take = hog::alignedReadSize(need, playback.ring.availableToRead(),
                                                  playback.bytesPerFrame);
    const std::size_t got = playback.ring.read(block.data(), take);
    if (got > 0) {
        std::fwrite(block.data(), 1, got, out);
        framesWritten += got / client.mBytesPerFrame;
        continue;
    }
    if (playback.producerDone.load(std::memory_order_acquire)) break;
    std::this_thread::sleep_for(std::chrono::milliseconds(2));
}
std::fclose(out);
std::printf("dump     : %llu frames em %s\n",
            static_cast<unsigned long long>(framesWritten), dumpPath.c_str());
```

### Task 11: Verificador contra o oráculo ffmpeg

**Files:**
- Create: `tools/verify_bitperfect.py`

**Interfaces:**
- Produces: `verify_bitperfect.py REF.raw DUMP.raw --bits 24` — sai 0 se idênticos, 1 se divergem, imprimindo o primeiro ponto de divergência.

- [ ] **Step 1: Escrever o verificador**

```python
#!/usr/bin/env python3
"""Compara o dump do player com o PCM de referência do ffmpeg.

O dump contém float32 (o formato que o device entrega ao IOProc); a referência contém
inteiros no bit depth original do arquivo. A comparação converte o float de volta para
inteiro: se a ida e volta for exata, os bytes têm de bater exatamente.
"""
import argparse
import struct
import sys


def read_int_samples(path, bits):
    """Lê PCM inteiro little-endian empacotado (3 bytes para 24 bits)."""
    width = bits // 8
    data = open(path, "rb").read()
    out = []
    for i in range(0, len(data) - width + 1, width):
        chunk = data[i:i + width]
        value = int.from_bytes(chunk, "little", signed=True)
        out.append(value)
    return out


def read_float_samples(path):
    data = open(path, "rb").read()
    count = len(data) // 4
    return list(struct.unpack(f"<{count}f", data[:count * 4]))


def main():
    p = argparse.ArgumentParser()
    p.add_argument("reference")
    p.add_argument("dump")
    p.add_argument("--bits", type=int, default=24)
    args = p.parse_args()

    ref = read_int_samples(args.reference, args.bits)
    dump = read_float_samples(args.dump)

    scale = float(1 << (args.bits - 1))
    n = min(len(ref), len(dump))
    if n == 0:
        print("ERRO: um dos arquivos está vazio")
        return 1

    mismatches = 0
    first = None
    for i in range(n):
        # float -> inteiro: exato quando o valor coube na mantissa de 24 bits.
        converted = int(round(dump[i] * scale))
        if converted != ref[i]:
            mismatches += 1
            if first is None:
                first = (i, ref[i], dump[i], converted)

    print(f"amostras comparadas : {n}")
    print(f"referência          : {len(ref)} amostras ({args.bits} bits)")
    print(f"dump                : {len(dump)} amostras (float32)")
    if mismatches == 0:
        print("resultado           : BIT-PERFECT — todas as amostras batem exatamente")
        return 0
    i, r, d, c = first
    print(f"resultado           : DIVERGE em {mismatches} de {n} amostras")
    print(f"primeira divergência: índice {i}, referência {r}, dump {d!r} -> {c}")
    return 1


if __name__ == "__main__":
    sys.exit(main())
```
