# Triage labels

Os skills usam cinco papéis canônicos, mapeados diretamente para os labels do rastreador:

| Papel canônico | Label no rastreador | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Issue a avaliar por manutenção |
| `needs-info` | `needs-info` | Aguarda mais informações de quem reportou |
| `ready-for-agent` | `ready-for-agent` | Especificada e pronta para agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será executada |

Quando um skill mencionar um papel, aplique o label correspondente desta tabela.
