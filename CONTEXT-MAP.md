# Context map

Este repositório tem dois contextos de domínio:

- **Core de áudio em Rust:** `rust/CONTEXT.md` — código em `rust/src/`.
- **Player/UI em Swift:** `apps/player/CONTEXT.md` — aplicação e integrações de interface.

Leia também as ADRs de sistema em `docs/adr/`. Os `CONTEXT.md` específicos serão criados e mantidos quando os conceitos de cada contexto forem explicitamente definidos.
