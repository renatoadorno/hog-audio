#
# Formato: uma exceção por linha, com quatro campos separados por "|":
#   pacote | valor no core | valor no protótipo | motivo
# Os valores são os que o gate imprime: cada versão com as features ativadas entre colchetes,
# separadas por " ; " quando o pacote aparece mais de uma vez (alvo e host), e "ausente" quando o
# pacote não está na árvore daquele lado. O motivo não leva "|" e cita o arquivo:linha de quem
# impõe a diferença. Linhas começadas por "#" e linhas vazias são ignoradas.
#
# O gate reprova se uma diferença não estiver aqui, se os valores de uma exceção não baterem com a
